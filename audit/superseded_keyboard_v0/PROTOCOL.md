# Protocol frozen before viewing test predictions
Date of protocol: 2026-10-27 (user timezone Asia/Bangkok)

Question: does train-only, ambiguity-weighted paired consistency improve CPU character n-gram classification beyond ordinary augmentation and uniform consistency?
Candidate name: CAPC (Collision-Aware Paired Consistency). This is an experimental variant, NOT a verified new algorithm.

Data: pinned ura-hcmut/UIT-VSFC and ura-hcmut/UIT-VSMEC. Public mirrors, CC BY-NC-SA 4.0 per dataset cards. Do not redistribute data in the software archive. ViHSD is gated and will not be accessed without authorization. Inspect counts rather than assume document counts.
Audit: normalize NFC/lowercase/whitespace for equality. Retain official training rows; remove dev rows matching train, and test rows matching either train or original dev. Deduplicate dev/test internally by canonical exact key, first occurrence kept. Report conflicting labels; folding collisions audited, not silently removed. Report official test results separately only if explicitly run; primary is decontaminated test. Training exact duplicates retained, with counts disclosed.
Models: word ridge, char ridge, char LinearSVC, fully folded ridge, raw+folded concatenation ridge, augmented char ridge, uniform paired-consistency ridge, CAPC, CAPC with shuffled weights (negative control).
Representation: char TF-IDF (2,5), min_df=2, max_features=30000, sublinear_tf=True, l2; vocabulary/IDF fit on training raw+folded only, shared by char methods; word TF-IDF (1,2), train only. Squared-loss multiclass ridge alpha in {1,10}. LinearSVC C in {0.5,2}. No intercept for ridge; each class receives equal total supervised row weight.
Training seeds: 17,29,43,71,101. Each augmented model receives clean, fully folded, and one stochastic noisy view per training row; stochastic view uniformly selects fold, keyboard, repeat or teencode at 30% token-selection probability. Each of three supervised views has weight 1/3. Pair penalty uses raw minus fully folded features, coefficient lambda in {0.3,3}. CAPC weights are exp(-4 * max token JSD), where JSD compares smoothed class-balanced label distributions of a surface form and its accent-folded family, estimated out-of-fold on training only (3-fold stratified split, seed=2026). Shuffled control uses same weights shuffled with training seed. Uniform uses all weights=1.
Selection: use training seed=17 and dev corruption seed=9001. Tune alpha/C and lambda on mean macro-F1 across clean + fold/keyboard/repeat/teencode at 30%, subject to clean macro-F1 no more than 1 percentage point below same-representation clean ridge (SVC exempt). If none feasible, choose best score and disclose infeasibility. Freeze selected hyperparameters in selected.json BEFORE evaluating test. The development corruption families are also seen during training: in-family tuning, not zero-shot noise tuning.
Test: 5 paired runs, each training seed evaluated with test corruption seed=100000+training_seed. Eight individual noise families: token fold, wrong tone, keyboard, delete, swap, repeat, whitespace, teencode; severities 0.1,0.2,0.3 token selection probabilities; plus clean, full folding, NFD Unicode. Preserve original labels as an unverified synthetic robustness assumption. Report actual change rate and changed token fraction, do not call 30% selected tokens 30% character edit rate. Whitespace operator joins selected inter-token boundaries. No semantics/human validation claimed.
Metrics: macro-F1 fixed label set, accuracy, per-class F1, condition mean excluding clean/fullfold/NFD, worst cell; changes from char baseline and best development-selected baseline. Paired bootstrap over original examples, with the same resampled indices for ALL perturbations and runs; average across runs (training+noise variation), 2000 replicates. A diagnostic, not full training-population inference. No individual noise cell treated as an independent sample. Report all runs and ablations, including losses.
Efficiency: full preprocessing+TF-IDF+prediction batch=1 p50/p95 over 150 predeclared test rows, 3 timing repeats, one-thread CPU; artifact pickle sizes; training wall time. No comparison to unrun Transformers.
Integrity tests: identity noise p=0, deterministic seeding, Unicode normalization, folded idempotence, no split overlap, train-only vocabulary sentinel, nonnegative bounded reliability, solver stationarity and extra-penalty response on toy system, reproducibility rerun of selected seed, checksums and complete condition count.
Decision gate: no Q1-ready claim from two synthetic-noise tasks. Proceed toward publication only if candidate beats augmentation AND uniform consistency in both tasks without >1pp clean loss; report CI and effect sizes. If gate fails, no-go for candidate rather than inventing novelty. Even if it passes, require independent real-noise/human validation, additional language or domain, matched neural baselines, adversarial comparison, and broader related-work verification before submission.
