# Bounded novelty assessment of the new branch

The current experiment tests useful implementations and mechanism separation. It does not certify global originality or journal suitability.

| Prior work/concept | What was inspected and consequence |
|---|---|
| [Mouratidis and Tang, Exact Processing of Uncertain Top-k Queries in Multi-criteria Settings, PVLDB2018](https://www.vldb.org/pvldb/vol11/p866-mouratidis.pdf) | The previous project audit inspected the primary paper Sections2–5. Possible-result unions, regional dominance and partition verification are established. This new branch changes the representation/computation for a discrete token budget; it does not establish a new possible-top-k problem or run the original RSA/JAA implementation. |
| [Fagin et al., Optimal aggregation algorithms for middleware, JCSS2003](https://doi.org/10.1016/S0022-0000(03)00026-6), [PODS version](https://doi.org/10.1145/375551.375567) | Title/DOI verified through Crossref in this turn; full algorithm was not reviewed anew. Threshold-based top-k evaluation is established. Compiling repeated bounds must be treated as an implementation/algorithm specialization, not a first use of thresholds or safe pruning. No direct runtime comparison to this publication is asserted. |
| [Mohri, Minimization algorithms for sequential transducers](https://doi.org/10.1016/S0304-3975(98)00115-7) | Crossref title/DOI metadata verified, not a full-text equivalence assessment. State equivalence/minimization has a long history. We cannot infer that a score/rank quotient is globally new simply because it is applied to token edits. |
| [Mohri, Finite-State Transducers in Language and Speech Processing, Computational Linguistics1997](https://aclanthology.org/J97-2003/) | Downloaded the primary PDF and inspected determinization/residual weights, pushing/minimization pp296–297 and on-demand construction p304. Weight redistribution and merging equivalent states, including large word-lattice reductions, predate this branch. Our common document-score shift is not itself the transducer algorithm, but normalizing weights before equivalence reduction has a close established analogue. No proof that the two complete algorithms are equivalent or distinct was obtained. This strengthens the need for a closest-method review rather than a firstness claim. |
| [Symmetry reduction in CSP model checking](https://doi.org/10.1007/s10009-019-00516-4) | Crossref title/DOI metadata verified, no full-method review. Grouping equivalent positions/permutations is an established verification idea; repeated-text grouping is a required matched control here. |
| [TASTIER, ICDE2010](https://chenli.ics.uci.edu/files/icde10-tastier.pdf), [Caching Historical Embeddings in Conversational Search](https://arxiv.org/abs/2211.14155) | Previous audit inspected the primary TASTIER paper and caching abstract. Fuzzy interaction and client-side result/document reuse predate this application. Ordinary exact-query memoization is added as an essential control, especially for repeated requests. |

Live web-search attempts in this turn returned empty tool errors. Crossref metadata lookups and a direct primary ACL-PDF fetch succeeded. This is a search-coverage limitation, not evidence that no closer method exists. Earlier full-source audits remain available at pool_study/RELATED_WORK.md and round3/RELATED_WORK_UPDATE.md. New sources above inspected only at metadata level are explicitly marked; no claim of full reading or reproduction follows.

The potentially useful contribution is a complete, independently checkable pipeline for exact finite-edit result unions after certified projection, with full-query workloads and measured whole-session costs. Common score-shift invariance, min-cost representatives, permutation symmetry, cached bounds and witness saturation are each standard principles. Whether their particular specialization constitutes a sufficient method contribution remains unresolved. Dataset/source/model disclosure and positive timing alone do not settle this question.
