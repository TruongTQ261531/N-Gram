# Run history and disclosed limitations

1. Environment packages could not be installed in a read-only user directory; a workspace-local virtual environment was created. No experiment was interpreted from failed installations.
2. Preparation rejected a standalone combining-accent token whose folded form was empty. The lattice contract was narrowed to same-NFC-length variants and the example retained raw-only; regression coverage was added. This happened before fitted-model scores. `prepare_v0.log` preserves the assertion.
3. The French Parquet text column is `review`; the adapter maps it to `text`. Initial preparation stack trace is in `prepare_v1.log`. The completed French preparation produced 5000/1000/1999 retained train/dev/test rows. Vietnamese prepared data were reused after this adapter correction, with identical encoder statistics and unchanged model methods.
4. Seven integrity tests passed, including 600 exact-vs-exhaustive random cases, direct factorization checks and finite-difference gradients. A 200-training-row/20-validation-row smoke run used deliberately tiny optimization caps to validate the code path; it was not used as test evidence or for changing the frozen hyperparameter grid.
5. Validation-only selection completed for all three tasks. Commit df2a708c61cb4f6beaf24c6d11d4366faba85469 froze the algorithm/source/config before French confirmation test execution.
6. Final fits used one numerical thread. To use the two-core quota, VSMEC and French ran the identical frozen `run.final` function in isolated dataset output directories; the original parent was stopped after complete VSFC arrays and repeat-fit checks to avoid duplicate VSMEC computation. Metrics and diagnostics are merged from complete saved outputs; no seed or method is selected by test performance. This changes job scheduling, not the model, objective, configuration or seed list. Training wall times under concurrent jobs are not a controlled speed comparison.
7. `optimizer_success=false` is retained where L-BFGS reaches its finite iteration cap. Exact oracle correctness does not imply solved robust training. Restricted/full separation diagnostics and a separate full-subgradient bound are reported without claiming global convergence when not supported.
8. Source PDFs used for novelty audit and raw corpora are retained locally only. Trained numerical models, per-example outputs, configs and checksums are intended for publication on the research branch.

9. The first profiling table had identical ru_maxrss across all subprocesses, indicating the parent corpus-loader high-water mark was inherited across fork/exec. Replaced the reported per-worker peak with /proc/self/status VmHWM, retained inherited ru_maxrss separately, and re-ran only profiling. Invalid memory readings are archived in audit/profile_v0_inherited_rss.csv. No model weights, predictions, hyperparameters or test metrics changed.
