# Round 2: Budgeted Orthographic Lattice Training (BOLT), experimental candidate
Date: 27 October 2026, Asia/Bangkok. No new human annotation. Existing task labels only.

Motivation: replace sampled-noise robustness evaluation with exact worst-case inference and robust training for a contextual sparse classifier. This is a method-development experiment, not a new benchmark. No claim of novel dynamic programming, robust optimization, or Q1 readiness is made merely by naming the method.

Novelty screen before implementation: ARC (EMNLP 2021) already handles programmable transformation certification/training for LSTMs; LipsLev (ICLR 2025) certifies convolutional classifiers under general Levenshtein edits; budgeted robust optimization and finite-state shortest paths are established. Candidate-specific contribution to investigate: a sparse canonical/surface architecture with adjacent-token interactions, an exact weighted-budget oracle preserving those interactions and coalescing duplicate forms, and joint training using that oracle. Must compare against canonical-only, same-architecture clean/random-augmentation/greedy-adversarial training, unary-only robust models and independent-factor bounds. Exactness and deployment speed are useful properties but do not alone establish publication novelty.

Data: previous pinned UIT-VSFC and UIT-VSMEC. Their old test scores have already been inspected; all new scores on those tests are EXPLORATORY, even with newly frozen parameters. A French Allocine official train/validation/test split supplies an independent, previously unexamined language/domain confirmation. Train on a deterministic stratified sample of 5000 French training rows, tune on 1000 official validation rows, and evaluate 2000 official test rows (seed 20261027), cap classifier input at 128 whitespace tokens for every method. This is a declared small-data experiment, not full-corpus SOTA. Use all available decontaminated Vietnamese training data for final fits; a deterministic 2000-row training subset is permitted ONLY for development screening, disclosed in logs. Do not change the blind French test subset after examining scores.

Threat model: each retained whitespace token may stay raw, lose tone marks only, or lose all Vietnamese/Latin combining marks (including Vietnamese d-stroke mapping); duplicate strings collapse to a single choice. A modification costs the number of changed NFC Unicode codepoints (equal-length orthographic variants). Total cost <=k. No token deletion, insertion, swap or arbitrary synonym threat is certified. Existing original label is the intended-message label under this defined transmission channel. This is NOT a claim that every resulting string retains its literal meaning to a human reader. We certify predictions over a defined string set, without human semantic labels.

Representation: train-only token character TF-IDF (2,5), cap 12000 features, fitted on training-derived unique forms; additive per-token raw and canonical branches, raw/canonical adjacent-token pair hashes (8192 bins each), length normalization fixed to sqrt(retained token count), and bias. No sentence-global L2 normalization or sublinear sentence TF: these would invalidate the additive factorization. Fixed representation shared by contextual baselines; canonical-only is exactly invariant to the stated accent-removal choices. Hashes computed from strings independently of test vocabulary. No parameter fit on validation or test text/labels.

Oracle: maximize competing-class minus intended-class score using budget x previous-form-state dynamic programming, O(n*k*q^2), q<=3; trace back witness. Independent-factor lower margin bound relaxes shared choices and budget as disclosed; greedy attack is an attack lower bound, never a certificate. Prove the DP recurrence and independently compare with exhaustive enumeration, including interacting-edge counterexamples, duplicate variants, zero budget, variable costs and negative weights. Certificate uses a strict positive margin and a numerical tolerance; no rounded score certificate.

Training candidate: cutting-plane optimization of a convex class-balanced clean/robust squared-hinge surrogate plus L2 penalty, with exact DP separation. Maintain candidate witnesses per (example, competing class), minimize the restricted max-witness objective, then add exact violating witnesses. Report optimizer success, stationarity diagnostic and final separation gap. A finite iteration cap is a computational limit, not proof of reaching the global robust optimum. Baseline greedy uses the same training loop with a greedy separation oracle. Random augmentation uses matched sampled views and the same surrogate. Unary-only robust model removes contextual surface-edge interactions. Canonical-only uses identical retained training rows, class balance and feature normalization.

Development: regularization alpha in {0.0001,0.001}, robust mixture eta in {0.3,0.7}, training budget k=3. Screen on training subset and validation only. Each fit starts from the same seed-specific clean initialization. Select by mean validation macro-F1 and exact robust accuracy at k={0,1,3}, with clean macro-F1 no more than 2 percentage points below the best same-architecture clean model; record infeasible fallback explicitly. Max 4 cutting-plane rounds for screening, 6 for final; L-BFGS iterations 30/50 respectively. If objective/oracle implementation fails validation tests, repair before interpreting numerical model results and log all corrections. No test-driven change to hyperparameter grid.

Final runs: seeds 17,29,43. Perturbation budget eval k={0,1,2,3,5}, plus two random corruption rates and full folding as out-of-budget diagnostics. Report clean macro-F1/accuracy, exact robust accuracy (all labels must retain positive margins), balanced robust accuracy, margin distributions, exact-oracle attack success, greedy misses, loose-bound certification gap, model/CPU costs, all seed results. Paired document bootstrap 2000 draws, same resampled originals for all runs/methods; report conditional CIs and no multiplicity-adjusted discovery claims. Repeat one seed, record checksums, predictions and worst-margin arrays. Freeze selected configuration before opening the French confirmation test.

Gate: require useful robust-accuracy and clean-performance tradeoff over BOTH canonical-only and random-augmentation controls, benefit over greedy/unary controls, exactness checks without mismatches and no false certificate against exhaustive checks. Any failure is reported and restricts claims. This is an internal feasibility gate, not a journal's acceptance criterion. A Q1 submission additionally needs a defensible specific novelty argument and matched closest-method comparisons; an absolute acceptance guarantee is impossible.

## Pre-fit specification clarification
Before any model score was produced, set alpha={0.0001,0.001} to account for additive feature scaling; all methods receive both values. Baseline eta=0.7 (clean/canonical eta=0); BOLT tests eta={0.3,0.7}. Validation objective is 0.5 clean macro-F1 + 0.25 balanced robust accuracy at k=1 + 0.25 balanced robust accuracy at k=3, with the stated 2pp clean constraint. The French screening subset is also capped at 2000 training examples. Test transforms deferred until freeze.

## Preparation guard before any fitted-model score
Real data contains a standalone combining accent token. Folding it would produce an empty token and break the fixed-token lattice assumption. Retain only same-NFC-length candidate forms; keep such tokens raw-only. Do not drop the example. Added a regression case. This narrows the certified transformation set explicitly; insertion/deletion and length-changing normalization are outside scope. Original preparation assertion failure preserved in prepare_v0.log.
