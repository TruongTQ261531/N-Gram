# Data and trained artifacts

Project software follows the repository's MIT license. Source corpora retain their own terms; software licensing does not relicense them.

- UIT-VSFC and UIT-VSMEC pinned public mirrors declare CC BY-NC-SA 4.0. Vietnamese label-derived outputs and trained artifacts are shared under those terms to the extent applicable. Cite the original UIT dataset publications; see the root download_manifest.json and results/DATA_LICENSE.md from round 1.
- Allociné source: https://huggingface.co/datasets/tblard/allocine ; card states MIT, attribution Théophile Blard, French sentiment analysis with BERT (2020), https://github.com/TheophileBlard/french-sentiment-analysis-with-bert . Exact bytes/revision are in fr_manifest.json. Respect upstream rights in reviews; no raw review corpus is redistributed here.

Public artifacts include numerical model parameters/character-gram vocabulary and label/prediction arrays for research verification. Full input text, model caches containing corpus strings, temporary profiling fixtures and source PDFs are excluded. There is no newly collected human annotation.
