# Finite-edit reusable ngram result pools

This application experiment addresses a missing property in the previous reference-retention study: a certified reusable candidate set containing every possible top-k result, including all boundary ties. It uses two new inherited text corpora and complete computational oracles, with no human/LLM annotation. It does not establish global novelty or Q1 readiness.

## Validate the published evidence

Python3.12 with numpy2.3.5:

```bash
pip install numpy==2.3.5
python pool_study/check_archive.py
```

This independently enumerates every saved finite state from the integer factors, checks all per-state top-k traces, cached/full equality, split coverage, fixed selections, source/factor hashes and summary consistency. It does not download upstream corpora. The original-text factor reconstruction is a distinct full-source replay, also completed locally and recorded in source-replay reports.

## Recompute from pinned original text

Use a separate checkout for a new run, preserve the published results elsewhere and use the same frozen source/configuration. The generator refuses to overwrite an existing results/dataset directory. At least8GiB memory is sufficient in the measured cloud run; no GPU or paid API is required.

```bash
pip install -r pool_study/requirements.txt
python pool_study/prepare.py --data /absolute/path/to/local-pool-data
python pool_study/test_core.py
python pool_study/run.py --data /absolute/path/to/local-pool-data --dataset arguana
python pool_study/run.py --data /absolute/path/to/local-pool-data --dataset scidocs
python pool_study/replay_sources.py --data /absolute/path/to/local-pool-data --dataset arguana --output source-replay-arguana.json
python pool_study/replay_sources.py --data /absolute/path/to/local-pool-data --dataset scidocs --output source-replay-scidocs.json
```

Original corpora/queries remain upstream and local; pickle indices are local-only and should only be loaded if generated by your own trusted run. Ordered document IDs in results identify every factor column. These are real inherited texts with compact generated edits, not naturally observed typo queries or a new relevance benchmark. Report first16-token truncation rather than interpreting these runs as full-query BEIR relevance results.

## Browser feature

The website supports at most500documents and the existing web integer scorer. Its finite error channels are broader than the compact channel in this Python experiment. `webapp/dist/pool.mjs` constructs safe pools with a declared resource fallback; `worker.mjs` creates a cache retaining original index weights, validates admissible replays, and rejects stale scope. Exported proof bundles carry the pool and its model/corpus identity. The browser and offline experiment have distinct version identities; offline latency is not claimed for the deployed browser.

```bash
node webapp/test-engine.mjs
node webapp/test-pool.mjs
python -m http.server 4173 --directory webapp/dist
```

Scientific correctness, reproducible artifacts, application usefulness, global novelty and journal acceptance are separate claims. See the report for both positive and negative outcomes.
