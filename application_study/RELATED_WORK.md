# Application expansion: bounded prior-art and data-license audit

Checked 30 October 2026. This is targeted primary-source screening for a browser-local fixed-point ngram retrieval application, not an exhaustive systematic review or a novelty certificate. Search terms and access depth are recorded in `sources.json`. No spelling corpus/dictionary was downloaded or redistributed during this audit. Existing round3 results were read for context and left unchanged.

## What could support a research claim

The candidate is an auditable **finite-query-lattice retention service**: a declared fixed-point additive scorer, exact-integer pairwise/Pareto checks, a rank-bound-based retrieval-depth policy, and independently replayable small-lattice records. Browser deployment, BM25, adaptive K, abstention, a typo dictionary, counterfactual inspection, and JSON export are established ideas individually. Their combination is a useful application, but does not by itself establish a new algorithm or a publishable dataset.

The browser scorer must have a new explicit identifier/configuration. Quantizing BM25 coefficients defines a different ranker from the frozen float64 round3 scorer. Exact integer certificate arithmetic certifies those quantized coefficients; it does not make logarithm/coefficient generation mathematically exact, establish equivalence to the float scorer, or formally verify the browser executable. Use integer arithmetic without overflow (for JavaScript `Number`, prove every intermediate stays within the exact-integer range; otherwise use `BigInt`).

## Exact meaning of adaptive K and abstention

Let `L(q,B)` be the explicitly enumerated token-state lattice, `r` the selected reference, and `R* = max_{q' in L(q,B)} rank(r;q')` with the declared unfavorable-tie convention. A sound upper bound `U >= R*` implies `r` appears in the recomputed top-K for **every** allowed future query when `K >= U`, with corpus, normalization, scorer and budget unchanged.

This property has several practical limits:

1. `K=U` is the smallest depth justified by that returned bound, not necessarily the minimum sufficient depth `R*`. Call it a *certified depth* or *smallest depth supported by this certificate*. Only complete exact enumeration/optimization establishes `R*` and a true minimum; even then the minimum is under the declared tie convention.
2. The current clean top-K set is not thereby guaranteed to contain all future winners or all needed evidence. The guarantee concerns the same reference `r` in each freshly ranked perturbed query. A robust union-of-results set would require a different target and proof.
3. If `U` exceeds a document cap, abstention means the certifier did not establish retention within that cap. It does not prove failure. An actual admissible witness with rank greater than the cap does prove failure for that reference/cap/tie target.
4. Retaining a reference does not establish that it is relevant, true, sufficient for an answer, or semantically appropriate after the edit. An authored reference ID is not an independent relevance judgment. No downstream RAG quality/safety claim follows without downstream evaluation.
5. An edit dictionary defines a finite permitted channel. It supplies neither empirical typo frequencies nor assurance that arbitrary future real user typos lie inside it. Vietnamese accent removal, keyboard errors, and spelling variants require separate declared channels; an English dictionary does not validate Vietnamese coverage.

These are mathematical consequences of the proposed property, not findings of a user study. Measure both certificate slack `U-R*` on exhaustive records and abstention/retention at fixed document caps. Report latency and bytes separately from returned K. Fixed-K, pairwise-only, support/Pareto, and exact-enumeration comparisons on identical records are more informative than presenting adaptive sizing alone as a method contribution.

## Dataset contribution that can be defended now

An authored English/Vietnamese knowledge base plus exhaustive small finite-state rank labels can be released transparently as a **v0.1 synthetic audit set**. The exact labels are computational ground truth for one declared scorer and lattice, not human relevance labels or a real typo distribution. Preserve corpus/query IDs, authorship, language, scorer/version/hash, all token choices and costs, normalization, ties, complete lattice size, per-state ranks, worst-rank witnesses, every certificate/cap/UNKNOWN status, and a verifier. Include both easy and inconclusive cases.

If spelling pairs from an existing human-curated resource are inserted into authored or benchmark queries, describe that portion as **semi-synthetic query corruption using a curated spelling-error channel**. The pairs are not evidence of naturally observed query logs; no frequency or semantic-preservation claim is supported. Separate keyboard-generated edits, accent edits, and dictionary transplants in provenance and metrics.

The narrower contribution hypothesis is a public collection of finite edit-lattice retrieval instances with complete rank-oracle outputs and independently checkable certificate traces. This could help measure bound tightness and reproduce counterexamples, but the bounded search did not establish global firstness or sufficient scale/diversity for a new benchmark paper. Do not call it a new natural dataset or guarantee Q1 novelty. Existing typo/robustness benchmarks and counterfactual-ranking tools are required comparisons.
