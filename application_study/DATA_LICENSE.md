# Application audit data

Code added by this project is MIT. The authored synthetic knowledge-base documents and query seeds are released under CC0-1.0. They are examples written for the workbench, not a company's actual policy/manual or natural query logs. No human semantic relevance labels are assigned.

The optional spelling channel imports **data only** from codespell revision `4ce1caed2f97a50031225545c9697d9ef885c09b`. Upstream dictionary files are CC BY-SA3.0, separately from codespell's GPLv2 code. Credit codespell contributors and its documented Wikipedia/project origins; source/license URL, byte hash and filtering/inversion changes accompany every export in `data-license.json`.

The selected spelling dictionary and combined dictionary-derived audit release are distributed under [CC BY-SA3.0](https://creativecommons.org/licenses/by-sa/3.0/). Preserve attribution, license notice and modification description. Do not relabel imported spelling pairs as originally authored MIT/CC0 data. No codespell program code was copied.

Applying curated spelling pairs to authored text creates semi-synthetic query transformations. They do not establish observed user frequencies, natural query behavior or semantic preservation. Exact rank labels describe one frozen integer scorer/lattice. They are computational labels, not human relevance judgments.

Browser imports remain local to the browser. A downloaded bundle can contain the visitor's full corpus/query text and must be reviewed before the visitor shares it. The application does not automatically publish user-generated records or collect them as a new research dataset.
